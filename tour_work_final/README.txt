TODOS CON HERNÁN · EL GRAND TOUR DE SUIZA
================================================

VERSIÓN FINAL · 92 PHOTO SPOTS OFICIALES

Incluye:
- Mapa Leaflet interactivo.
- 92 marcadores numerados del 01 al 92.
- Hernán muy pequeño dentro del mapa.
- Animación de Hernán al seleccionar un Photo Spot.
- Ficha lateral con imagen grande y nítida.
- Carrusel inferior de los 92 spots.
- Botón ← para retroceder.
- Botón → para avanzar.
- Navegación circular: 01 ←→ 92.
- Buscador.
- Código separado en HTML, CSS y JavaScript.
- Comentarios de tipo "TÍTULO:" en las principales secciones del código.
- 92 imágenes de referencia del prototipo, preparadas a mayor resolución para la interfaz.
- Cada spot incluye su enlace directo a la página oficial de Switzerland Tourism.
- Las fotografías oficiales no se redistribuyen dentro del ZIP por derechos de uso.

CÓMO ABRIRLO
------------
Recomendado:
1. Abre la carpeta con Visual Studio Code.
2. Instala/usa Live Server.
3. Pulsa "Go Live".
4. Abre el proyecto en el navegador.

También:
python -m http.server 8000
